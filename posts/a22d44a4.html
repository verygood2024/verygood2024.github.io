发表于2026-07-25|更新于2026-08-03|yesandnoandperhaps
|总字数:2.6k|阅读时长:8分钟

前言

  首先感谢您对本站的关注！本文面向有意使用 Markdown 或本站扩展标签进行排版的投稿人，属于进阶说明，非必读内容。如果您仅需提交纯文本稿件，可直接关闭本文，按常规方式填写表单即可，不影响投稿。
  投稿系统完整支持 Markdown 语法及本站自有的扩展标签。您可在正文输入框中按相应格式书写，输入阶段显示为纯文本，稿件发表后将自动渲染为排版样式。
  上述功能均属可选，您可根据实际需要决定是否使用，无需额外费心。

  也许在不远的将来，我们的文本框会支持实时渲染 Markdown 语法。

什么是 Markdown？

  Markdown 是一种轻量级的文本格式化语法，用简单的符号就能实现标题、列表、加粗、链接等效果。
您不需要学习复杂的代码，只要记住几个常用符号即可。

示例：在输入框里写 **加粗文字**，最终显示出来就是加粗文字。

8. 空格用法

  在投稿输入框中，空格有两种完全不同的用途：排版留白与语法标记。请根据需要正确区分。

  · &emsp;（排版空格）
    用于在页面上制造可见的空白，如段落首行缩进、文字间距。输入 &emsp; 后，网页上会渲染为一个全角宽度的空白。
    示例：文字&emsp;文字 → 文字 文字

  · 普通空格（键盘空格键）
    用于 Markdown 语法结构和块标记语法。它不会被渲染为可见留白，而是被解析为标记的一部分。
    示例：# 标题、- 列表项、`{% note success flat %}` 中的空格都必须用普通空格。

8.1 相关注意事项与示例

  段落的首行缩进由系统自动完成。即便您不手动添加&emsp;，最终渲染时也会自动补上两个&emsp;的缩进量。因此，请勿在段首重复添加。

使用示例显示效果

  内容A 内容B（段落1）
  内容A  内容B（段落2）
    内容（段落3）
    内容（段落4）
  内容（段落5）
  内容（段落6）

  请勿在标签语法内部使用 &emsp; 替代普通空格

  诸如 `{% note success flat %}`、`{% new_note tip 标题 %}`、`{% cq %}` 等块标记，参数之间的空格必须使用普通空格，绝不能写成 `{% note success flat %}`，否则标签将无法被后台识别，导致排版错误。

  · 错误示范：`{% cq %}` → 居中块失效
  · 正确写法：`{% cq %}`

  内容区域可自由使用空格

  在这些块标记内部所包裹的内容区域（包括列表项、注释块正文、居中块正文、Obsidian样式注释块正文等），你可以根据需要随意使用普通空格和 &emsp; 进行排版，完全不受限制，例如如下内容编写与对应展示。

2026.7.18投稿板块更新内容介绍

  本段介绍摘自《投稿2025》“第四条之一、文集投稿·文集创建”，具体操作请以原文为准，本页可能存在更新滞后。

（一）文集投稿

对我们开放的文集进行投稿，截至2026.7.19，网站开放的文集有《残芰朱萼》（若日后有更多开放文集，该页面可能不会及时更新）。

（二）创建文集

当前网站文集分为两类：云辑与素辑。

创建云辑

云辑适用于多人联合投稿，或单一作者投稿作品数量达三十篇以上且题材跨度较大、需按章节分卷展示的情形。不符合云辑标准的投稿，将自动归入素辑。

云辑的创建周期一般为30至60个工作日。如投稿作品数量庞大且细分类目较多，创建时间可延长至365个工作日。（网站将分批上传作品，前述时限为整体完成期限。）

关于投稿云辑时投稿页的使用

若是单一作者投稿作品数量达三十篇以上且题材跨度较大、需按章节分卷展示的情形进行云辑投稿。可使用以下方式为作品分类：

文集简介框：
main：云辑本身的简介、序引、题记、楔子等
分类名1：分类的简介、序引、题记、楔子等
分类名2：同上
分类名3：同上
…

作品分类标注方式：
如需将某篇作品归入特定分类，请在作品的“额外要求”栏中单独占一行输入以下格式的标签：
tag:分类名2或分类名2。

示例：
作品1需要分类到分类名2中，则需要在作品1的额外要求栏中输入tag:分类名2或分类名2。
作品2需要分类到分类名3中，则需要在作品2的额外要求栏中输入tag:分类名3或分类名3。

注意：无论采用何种格式的标签，请让它们必须占一行。

也许在未来更多人使用该功能后，我们将开发更简便的方案。

创建素辑

素辑适用于作品数量不少于两篇的情形。

素辑的创建周期一般为9至14个工作日。投稿作品超过五篇的，每增加五篇，创建时间延长9个工作日。（网站将按每四至五篇一批次的方式分批上传。）
